# BookSpace
React SPA: віртуальна бібліотека та галерея зображень (лабораторна №8 + фінальний проєкт).

## Запуск
Потрібен Node.js 22.12+ (або підтримувана новіша LTS).
```bash
npm install
npm run dev
```
Відкрийте адресу, яку виведе Vite. Для пошуку книг створіть ключ Google Books API у Google Cloud Console, увімкніть Books API, обмежте ключ цим API та HTTP referrers вашого сайту. Скопіюйте `.env.example` у `.env.local` і заповніть `VITE_GOOGLE_BOOKS_KEY`. Перезапустіть Vite. Ключ фронтенду видимий користувачам; не використовуйте секретні ключі. Без ключа запит може бути відхилено. Галерея Wikimedia Commons ключа не потребує. Посилання під фотографіями ведуть на сторінки джерел із ліцензією та авторством.

## Перевірка
```bash
npm test -- --runInBand
npm run lint
npm run build
```
Перший запуск Jest створить snapshot; перевірте його і додайте `src/__tests__/__snapshots__/` до Git. Для свідомого оновлення: `npm test -- -u --runInBand`. Тести використовують mock fetch, а не мережу.

## Маршрути
- `/` — головна
- `/search` — Google Books
- `/library` — колекції, прогрес, фільтрація, видалення
- `/add`, `/edit/:id` — форма з валідацією
- `/gallery` — фотографії, loading/error, повторний запит

Стан колекцій піднято в LibraryProvider (Context + useState); useEffect синхронізує його з localStorage. Збереження локальне для одного браузера. Форма та пошук мають локальний стан. API-запити скасовуються при демонтуванні.

## Деплой Netlify
Створіть GitHub-репозиторій, завантажте код, підключіть його до Netlify. Build command: `npm run build`, Publish directory: `dist`. Додайте `VITE_GOOGLE_BOOKS_KEY` у змінні середовища для build та дозвольте домен у налаштуваннях обмежень ключа. `public/_redirects` забезпечує маршрути SPA. Після деплою перевірте пряме відкриття `/gallery`, пошук, збереження після перезавантаження, форму, обробку помилок.

## Демонстрація для захисту
1. Головна та маршрути без перезавантаження.
2. Пошук книги, додавання до колекції, зміна статусу.
3. Ручне додавання та редагування книги, перевірка обов'язкових полів.
4. Перезавантаження сторінки — колекція зберігається.
5. Галерея: API, картки, стани завантаження та помилки.
6. Результати Jest, ESLint, build; посилання GitHub та Netlify.

Примітка: залежності, реальні API та збірку потрібно перевірити у локальному середовищі.
